## О проекте

`SyntheticHealthSimulator` генерирует реалистичные (с точки зрения статистических закономерностей) панельные данные о состоянии здоровья виртуальной популяции на протяжении 20 лет. Каждый «пациент» имеет:

- **Демографические характеристики** (возраст, пол, рост);
- **Генетический профиль** (полигенные риски);
- **Историю образа жизни** (питание, физическая активность, курение, сон, стресс);
- **Ежегодно измеряемые биомаркеры** (вес, артериальное давление, холестерин, HbA1c).

На основе этих данных рассчитываются риски развития различных заболеваний (сердечно-сосудистые заболевания, диабет 2 типа, инсульт, НАЖБП, колоректальный рак, цирроз) и моделируются исходы.

**Основная цель** — создание качественных наборов данных для обучения моделей прогнозирования, исследования влияния факторов образа жизни и тестирования алгоритмов обработки пропущенных данных.

## Обзор пайплайна

1. **Генератор** (`scripts/generate.py`)
    - Базовая когорта (демография, генетика, исходные биомаркеры)
    - 20-летние траектории образа жизни (процессы ОУ)
    - Ежегодная эволюция биомаркеров с шумом
    - Расчет рисков заболеваний (SCORE2, FINDRISC-подобные)

2. **Выходные наборы данных** (5 CSV-файлов)
    - `01_cohort_baseline` — неизменяемые характеристики
    - `02_lifestyle_history` — ежегодные факторы образа жизни
    - `03_biomarkers_history` — ежегодные биомаркеры с шумом
    - `04_health_risks` — 10-летние риски и исходы
    - `05_aggregated_dataset_with_missing` — готово для ML с пропусками MAR

3. **Валидация** (`scripts/validate.py`)
    - Структура и полнота файлов
    - Физиологические диапазоны (жёсткое ограничение)
    - Временные тренды и корреляции
    - Распространённость заболеваний и коморбидность
    - Паттерны пропусков MAR и согласованность между наборами
    - Создаёт текстовый отчёт в `output/validation_report.txt`

4. **Статистика** (`scripts/statistics.py`)
    - Собирает исчерпывающую статистику по всем пяти наборам в единый CSV-файл
    - Сохраняет в `output/statistics/all_statistics.csv`

5. **Визуализация** (`scripts/visualize.py`)
    - Создаёт 8 типов графиков из файла статистики:
      - временные тренды, эволюция распределений, процентильные ленты,
        распределения дельт, сводная панель, сравнение с референсом,
        тепловая карта отклонений и итоговый отчёт.
    - Сохраняет графики и отчёт в `output/visualizations/`

6. **Скрипты для анализа** (5 Python-скриптов в папке `analysis/`)
    - `01_cohort_baseline_analysis.py` – исследование базовой когорты
    - `02_lifestyle_history_analysis.py` – анализ траекторий образа жизни
    - `03_biomarkers_analysis.py` – тренды и шум биомаркеров
    - `04_health_risks_analysis.py` – валидация моделей рисков
    - `05_aggregated_complete_pipeline.py` – полный ML-пайплайн с пропущенными данными

Проект написан на Python 3.14+ и использует следующие зависимости:

```bash
# Установка зависимостей (через pip)
```

## Использование

### Базовая генерация данных

Генерация данных для 5000 человек с периодом наблюдения 20 лет:

```bash
python scripts/generate.py
```

Все настройки определены в `src/config.py` и `src/coefficients.py`. Вы можете переопределить параметры через аргументы командной строки:

| Аргумент          | Описание                               | По умолчанию           |
|-------------------|----------------------------------------|------------------------|
| `--people`, `-p`  | Целевое количество пациентов           | 5000                   |
| `--years`, `-y`   | Период наблюдения (лет)                | 20                     |
| `--seed`, `-s`    | Случайное зерно                        | 42                     |
| `--output`, `-o`  | Директория вывода (по умолчанию `data/synthetic_v*`) | авто |
| `--quiet`, `-q`   | Подавить информационный вывод           | False                  |

Пример:
```bash
python scripts/generate.py --people 1000 --years 10 --seed 123
```

После завершения в указанной директории создаются пять CSV-файлов.

### Валидация данных

Валидация сгенерированного набора (автоматически использует последнюю версию):

```bash
python scripts/validate.py
```

Выполняются все проверки, и отчёт сохраняется в `output/validation_report.txt`. При обнаружении критических ошибок скрипт завершается с ненулевым кодом.

### Генерация статистики

Создание единого CSV-файла со сводной статистикой по всем наборам:

```bash
python scripts/statistics.py
```

Выходной файл: `output/statistics/all_statistics.csv`

### Визуализация

Создание 8 графиков из файла статистики:

```bash
python scripts/visualize.py
```

Результаты сохраняются в `output/visualizations/`:
- 8 SVG-графиков
- `reference_comparison_table.csv`
- `validation_summary_report.txt`

## Скрипты для анализа

Репозиторий включает пять самодостаточных Python-скриптов (ранее Jupyter-ноутбуки) для углублённого анализа каждого набора данных. Они используют общие хелперы из `src.utils.analysis_helpers` и создают выходные файлы в `output/analysis/`.

### Скрипт 1: Анализ базовой когорты (`analysis/01_cohort_baseline_analysis.py`)

**Цель:** Исследование статических характеристик и предсказательной силы исходных данных.

**Выходные данные:** таблицы и графики в `output/analysis/01_cohort_baseline/`

### Скрипт 2: Анализ истории образа жизни (`analysis/02_lifestyle_history_analysis.py`)

**Цель:** Анализ 20‑летних траекторий, процессов ОУ, стрессовых событий, кластеризация.

**Выходные данные:** `output/analysis/02_lifestyle_history/`

### Скрипт 3: Анализ биомаркеров (`analysis/03_biomarkers_analysis.py`)

**Цель:** Проверка жёсткого ограничения, оценка шума, временные тренды, удаление шума.

**Выходные данные:** `output/analysis/03_biomarkers/`

### Скрипт 4: Анализ рисков для здоровья (`analysis/04_health_risks_analysis.py`)

**Цель:** Валидация формул рисков, калибровка, модели прогнозирования заболеваний.

**Выходные данные:** `output/analysis/04_health_risks/`

### Скрипт 5: Полный ML-пайплайн (`analysis/05_aggregated_complete_pipeline.py`)

**Цель:** Полный цикл ML на агрегированном наборе данных с пропусками MAR.

**Выходные данные:** `output/analysis/05_aggregated_pipeline/`

## Структура сгенерированных данных

Все файлы, кроме агрегированного, имеют панельную структуру: одна строка или набор показателей хранится для каждого пациента и года наблюдения.

### 1. Базовая когорта (`01_cohort_baseline_v*.csv`)

Одна строка на пациента. Содержит неизменяемые характеристики и исходные значения.

| Категория                  | Колонки                                                                                                                                                  |
|----------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------|
| Идентификатор и демография | `person_id`<br/>`age_start`<br/>`sex`<br/>`height_cm`                                                                                                    |
| Антропометрия              | `weight_start_kg`<br/>`bmi_start`<br/>`muscle_mass_start`                                                                                                |
| Энергетический метаболизм  | `bmr_start_kcal`<br/>`base_calories`                                                                                                                     |
| Генетические риски         | `genetic_risk_cvd`<br/>`genetic_risk_diabetes`<br/>`genetic_risk_stroke`<br/>`genetic_risk_nafld`<br/>`genetic_risk_cancer`<br/>`genetic_risk_cirrhosis` |
| Исходные биомаркеры        | `initial_hdl_mgdl`<br/>`initial_total_cholesterol_mgdl`<br/>`initial_sbp_mmhg`<br/>`initial_hba1c_percent`                                               |
| Латентные факторы          | `lipid_factor_hdl`<br/>`lipid_factor_tc`                                                                                                                 |

### 2. История образа жизни (`02_lifestyle_history_v*.csv`)

Показатели образа жизни и расчётные параметры записываются для каждого пациента и каждого года.

| Категория                        | Колонки                                                                                                                                                                                                                                         |
|----------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Идентификатор, год, возраст      | `person_id`<br/>`age_{year}`                                                                                                                                                                                                                    |
| Физические показатели (истинные) | `weight_kg_true_{year}`<br/>`muscle_mass_factor_true_{year}`<br/>`bmr_kcal_true_{year}`<br/>`tdee_kcal_true_{year}`                                                                                                                             |
| Питание                          | `protein_pct_{year}`<br/>`fat_pct_{year}`<br/>`carb_pct_{year}`<br/>`saturated_fat_pct_{year}`<br/>`fiber_g_day_{year}`<br/>`sodium_mg_day_{year}`<br/>`macro_imbalance_{year}`<br/>`simple_carbs_g_{year}`                                     |
| Образ жизни                      | `alcohol_g_per_week_{year}`<br/>`cardio_met_minutes_{year}`<br/>`strength_met_minutes_{year}`<br/>`total_met_minutes_{year}`<br/>`cigarettes_per_day_{year}`<br/>`stress_level_{year}`<br/>`sleep_hours_{year}`<br/>`cumulative_smoking_{year}` |

### 3. Биомаркеры (`03_biomarkers_history_v*.csv`)

Ежегодные значения биомаркеров (с добавленным шумом).

| Категория          | Колонки                                                                                                                       |
|--------------------|-------------------------------------------------------------------------------------------------------------------------------|
| Идентификатор, год | `person_id`<br/>`age_{year}`                                                                                                  |
| Биомаркеры         | `weight_kg_{year}`<br/>`hdl_mgdl_{year}`<br/>`total_cholesterol_mgdl_{year}`<br/>`sbp_mmhg_{year}`<br/>`hba1c_percent_{year}` |
| Производные        | `bmi_{year}`<br/>`bmi_corrected_{year}`<br/>`non_hdl_mgdl_{year}`<br/>`non_hdl_mmol_{year}`<br/>`muscle_mass_factor_{year}`   |

### 4. Риски и исходы (`04_health_risks_v*.csv`)

Рассчитанные 10-летние риски и бинарные флаги наличия заболеваний за весь период наблюдения.

| Категория     | Колонки                                                                                                                                                       |
|---------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Идентификатор | `person_id`                                                                                                                                                   |
| Риски         | `cvd_risk_10year`<br/>`diabetes_risk_10year`<br/>`stroke_risk_10year`<br/>`nafld_risk_10year`<br/>`colorectal_cancer_risk_10year`<br/>`cirrhosis_risk_10year` |
| Исходы        | `has_cvd`<br/>`has_diabetes`<br/>`has_stroke`<br/>`has_nafld`<br/>`has_colorectal_cancer`<br/>`has_cirrhosis`                                                 |
| Дополнительно | `health_score`<br/>`primary_death_cause`<br/>`estimated_event_age`<br/>`sex`                                                                                  |

### 5. Агрегированный набор данных с пропусками (`05_aggregated_dataset_with_missing_v*.csv`)

Одна строка на пациента. Содержит усреднённые и начальные/конечные значения факторов образа жизни, финальные биомаркеры, риски, исходы и синтезированные пропущенные значения (через механизм MAR).

**Пропущенные значения могут появляться в колонках:** `final_sbp_mmhg`, `final_hdl_mgdl`, `final_total_cholesterol_mgdl`, `final_hba1c_percent`, `avg_alcohol_g_per_week`, `avg_total_met_minutes`.

| Категория                        | Колонки                                                                                                                                                                                                                        |
|----------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Идентификатор и демография       | `person_id`<br/>`sex`<br/>`age_start`<br/>`age_end`                                                                                                                                                                            |
| Усреднённые факторы образа жизни | `avg_alcohol_g_per_week`<br/>`avg_total_met_minutes`<br/>`avg_sleep_hours`<br/>`avg_stress_level`<br/>`avg_fiber_g_day`<br/>`avg_sodium_mg_day`<br/>`avg_saturated_fat_pct`<br/>`avg_simple_carbs_g`<br/>`avg_macro_imbalance` |
| Динамика веса и мышечной массы   | `bmi_start`<br/>`final_bmi`<br/>`weight_start_kg`<br/>`final_muscle_mass`                                                                                                                                                      |
| Финальные биомаркеры             | `final_hdl_mgdl`<br/>`final_total_cholesterol_mgdl`<br/>`final_sbp_mmhg`<br/>`final_hba1c_percent`<br/>`final_non_hdl_mmol`                                                                                                    |
| Курение                          | `cumulative_smoking_end`                                                                                                                                                                                                       |
| Генетические риски               | Все 6 рисков (как в файле 1)                                                                                                                                                                                                   |
| Риски и исходы                   | Все 6 рисков и исходов (как в файле 4)                                                                                                                                                                                         |
| Дополнительно                    | `health_score`<br/>`primary_death_cause`<br/>`estimated_event_age`                                                                                                                                                             |

## Калибровка и конфигурация

Все коэффициенты в модели **намеренно снижены** по сравнению с эпидемиологическими данными для предотвращения доминирования одного фактора и обеспечения сбалансированного обучения ML-моделей.

### Ключевые настраиваемые параметры:

| Параметр               | Описание                                 | Значение по умолчанию     |
|------------------------|------------------------------------------|---------------------------|
| `diabetes_threshold`   | Регулирует распространённость диабета    | 17 (~15%)                 |
| `risk_intercepts`      | Свободные члены логистических моделей    | ССЗ: -5.5, Инсульт: -5.5  |
| `boundary_coefficient` | Коэффициент оверсемплинга для фильтрации | 1.35                      |

**Целевая распространённость заболеваний:**

- ССЗ: ~10‑15%
- Диабет: ~10‑15%
- Инсульт: ~5‑10%
- Коморбидность (2 и более заболевания): 15‑50%

Остальные коэффициенты (SCORE2, курение, алкоголь, натрий) подробно описаны в [Научном описании](SCIENTIFIC_REFERENCE_RU.md).
